# Chuleta SQL para MySQL

Referencia práctica en español con comandos SQL organizados por acciones, desde la creación de bases de datos y tablas hasta consultas, relaciones, transacciones y administración.

## Contenido

- [Chuleta de SQL para MySQL](./chuleta_mysql.md): explicaciones breves, ejemplos sencillos y buenas prácticas.

## Requisitos

- MySQL 8.0 o superior para los ejemplos de CTE, funciones de ventana y otras características modernas.
- Algunas operaciones administrativas, importaciones y exportaciones requieren permisos adicionales o configuración del servidor.

## Uso

Abre [`chuleta_mysql.md`](./chuleta_mysql.md) en GitHub o descárgalo para consultarlo. La guía incluye un esquema de ejemplo para que puedas probar las consultas en una base de datos propia.

> Los ejemplos son educativos. Revisa las condiciones de `UPDATE` y `DELETE` antes de ejecutarlos, y no uses las credenciales ilustrativas en producción.

## Temas incluidos

- Bases de datos, tablas, columnas y tipos de datos.
- Inserción, consulta, filtrado, ordenamiento, agrupación, actualización y eliminación.
- `JOIN`, subconsultas, CTE, funciones de ventana y combinación de resultados.
- Restricciones, índices, vistas y transacciones.
- Usuarios, permisos, diagnóstico, importación y exportación.
- Procedimientos, funciones, disparadores y funciones integradas de MySQL.
